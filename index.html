Trying the examples

  1. 1
    Open a demo.

    Everything runs in this tab; there is no login or setup.

  2. 2
    Use the included sample data.

    Call trades starts with a fictional roster. You can also test your own synthetic .csv or .xlsx file.

  3. 3
    Inspect or export the result.

    Exports are browser downloads. Suggested swaps are not submitted, agreements are not authenticated and no roster is modified.

Implementation notes

Scope

This is a front-end-only proof of concept. State is kept in the current browser tab, without a server or database. No user accounts, shared records, scheduling integration, notifications, or verifiable electronic signatures.

Source material

The learning-objective list contains illustrative themes, not an authoritative Royal College objective catalogue. Linked references are reading suggestions rather than validated chapter-level mappings. Review against current official program standards before implementation.

Data handling

Do not enter real resident names, confidential schedules or patient information on this public demo. Production deployment would require authentication, authorization, consent, audit logs and an approved hosting/storage arrangement.
